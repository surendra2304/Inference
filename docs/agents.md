# Specialist Agents & Roles

## Overview
Agents are not separate physical AI models. An agent is an identity composed of:
- Distinct role & operational objective
- Role-specific system instructions & heuristics
- Memory access scope (`agent_id`)
- Allowed tools & provider configuration
- Evaluation & performance history

## 10 Initial Specialist Roles
1. **Researcher**: Information gathering, knowledge synthesis, citation checks.
2. **Architect**: High-level system design, modular contracts, component boundaries.
3. **Coder**: Concrete implementation, refactoring, API integration.
4. **Debugger**: Error diagnosis, root-cause investigation, edge cases.
5. **Security Analyst**: Threat modeling, injection defense, privilege escalation prevention.
6. **Data Analyst**: Numerical reasoning, structured data validation, metrics.
7. **Critic**: Adversarial red-teaming, logical fallacy identification, stress-testing.
8. **Fact Checker**: Claim vs. evidence verification, contradiction detection.
9. **Strategist**: Tradeoff analysis, cost-benefit comparison, roadmap prioritization.
10. **Synthesizer**: Resolves conflicts, combines surviving claims, flags explicit uncertainty.
